## 이런 상황인가요?

- 내 컴퓨터에서는 바뀌었는데 배포 주소는 예전 화면 그대로입니다.
- 새로고침을 여러 번 해도 옛날 내용이 보입니다.
- Vercel 배포 목록에 새 배포가 만들어지지 않았습니다.
- 휴대폰에서만 예전 화면이 보입니다.

## 먼저 확인할 것

수정한 내용은 내 컴퓨터, GitHub, Vercel 세 곳을 차례로 거쳐 배포됩니다. 어디까지 갔는지 앞에서부터 확인하면 됩니다.

<Steps>
<Step title="브라우저가 옛 화면을 저장해 두고 있는지 봅니다">
브라우저는 한 번 받은 파일을 저장해 두었다가 다시 씁니다. 그래서 바뀌었는데도 예전 화면이 보일 수 있습니다.

그렇다면 Ctrl 키와 함께 새로고침하거나, 시크릿 창에서 주소를 열어 보세요. 여기서 새 내용이 보이면 배포는 정상입니다.
</Step>
<Step title="GitHub에 실제로 올라갔는지 봅니다">
Claude가 파일을 고쳤어도 GitHub에 올리지 않았다면 배포는 시작되지 않습니다.

그렇다면 github.com에서 내 저장소를 열어 마지막 변경 시각을 확인하세요. 방금 시각이 아니라면 아직 올라가지 않은 것입니다.
</Step>
<Step title="Vercel에 새 배포가 생겼는지 봅니다">
배포 목록에 방금 만들어진 배포가 있는지 확인합니다.

그렇다면 상태를 봅니다. 진행 중이면 기다리고, 실패로 표시되면 [Vercel 배포에 실패했어요](/troubleshooting/vercel-deploy-fails)를 보세요.
</Step>
<Step title="보고 있는 주소가 맞는지 봅니다">
Vercel은 배포마다 별도의 주소를 함께 만듭니다. 예전 배포의 주소를 즐겨찾기에 넣어 두면 계속 옛 화면이 보입니다.

그렇다면 Vercel 프로젝트 화면에서 대표 주소를 다시 확인하고 그 주소로 여세요.
</Step>
<Step title="배포가 끝났는지 확인합니다">
배포에는 시간이 조금 걸립니다. 진행 중일 때 새로고침하면 아직 예전 화면이 보입니다.

그렇다면 배포 상태가 완료로 바뀐 뒤에 다시 새로고침하세요.
</Step>
</Steps>

## 휴대폰에서만 예전 화면이 보인다면

휴대폰 브라우저도 한 번 받은 화면을 저장해 둡니다. 컴퓨터에서는 새 내용이 보이는데 휴대폰만 그대로라면 이 경우입니다.

휴대폰에서 해당 탭을 완전히 닫았다가 주소를 다시 열어 보세요. 그래도 그대로면 시크릿 창에서 열어 확인합니다.

## Claude에게 이렇게 말해보세요

<PromptBox>
방금 수정한 내용이 배포한 사이트에 보이지 않아. 지금 프로젝트에 저장하지 않은 변경 사항이 있는지 확인하고, GitHub에 올라간 마지막 내용이 무엇인지 알려 줘. 아직 올라가지 않았다면 커밋하고 올려 줘. 코드 내용은 바꾸지 마.
</PromptBox>
