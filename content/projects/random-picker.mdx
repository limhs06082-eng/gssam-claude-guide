## 무엇을 만드나요

이름을 넣어 두고 무작위로 한 명을 뽑는 도구를 만듭니다. 발표자 정하기, 순서 정하기, 모둠 나누기에 씁니다.

앞의 두 프로젝트와 다른 점은 목록을 다룬다는 것입니다. 여러 개의 값을 넣고, 보여 주고, 지우고, 그중에서 하나를 고릅니다. 이 구조는 앞으로 만들 거의 모든 앱에 나옵니다.

## 생각하기

| 질문 | 이 앱의 답 | 그래서 |
| --- | --- | --- |
| 데이터를 저장해야 합니까? | 지금은 아니요 | 저장 기능 없이 시작합니다 |
| 현재 기기에서만 써도 됩니까? | 예 | 나중에 저장한다면 LocalStorage로 충분합니다 |
| 여러 사람이 같은 데이터를 봐야 합니까? | 아니요 | 데이터베이스가 필요 없습니다 |
| 사용자를 구분해야 합니까? | 아니요 | 로그인이 필요 없습니다 |

첫 줄이 앞의 두 프로젝트와 다릅니다. 이름을 매번 다시 입력하는 것이 번거로울 수 있기 때문입니다.

그래도 처음에는 저장 없이 만듭니다. 이유가 두 가지 있습니다. 저장이 붙으면 확인할 것이 늘어나서 뽑기 기능 자체가 잘 되는지 보기 어려워집니다. 그리고 정말 불편한지는 몇 번 써 봐야 알 수 있습니다.

불편하다는 것을 확인한 다음에 붙이는 것이 순서입니다. 그 순서를 [개인 업무 체크리스트](/projects/personal-checklist)에서 그대로 밟습니다.

이름을 다루는 앱이므로 한 가지 더 정해 둡니다. 학생 실명 대신 번호나 별명을 쓸지 정하세요. 이 앱은 아무것도 저장하지 않으므로 입력한 이름이 어딘가로 전송되지는 않습니다. 다만 교실 앞 화면에 이름이 크게 뜬다는 점은 미리 생각해 두는 편이 좋습니다.

## 기획하기

누가 쓰나요. 수업하는 교사입니다. 뽑힌 결과는 학생들이 함께 봅니다.

무엇을 할 수 있어야 하나요. 이름을 여러 개 넣고, 목록을 확인하고, 하나를 무작위로 뽑습니다. 잘못 넣은 이름은 지울 수 있어야 합니다.

화면에 무엇이 보여야 하나요. 위쪽에 이름 입력 칸, 그 아래에 지금 들어 있는 이름 목록, 가운데에 뽑기 버튼, 그리고 뽑힌 이름이 크게 나오는 자리입니다.

한 가지 결정할 것이 있습니다. 한 번 뽑힌 사람을 다시 뽑을 수 있게 할지입니다. 발표 순서를 정할 때는 제외하는 편이 좋고, 단순 추첨이라면 그대로 두어도 됩니다. 이 결정을 요청에 넣습니다.

## Claude에게 요청하기

새 폴더를 만들어 Claude Code 앱에서 엽니다.

<PromptBox>
무작위로 한 명을 뽑는 웹앱을 만들어 줘. 지금은 빈 폴더야.

수업 중에 발표자를 정할 때 쓸 거야. 이름을 하나씩 입력해서 목록에 넣고, 뽑기 버튼을 누르면 그중 한 명이 무작위로 뽑혀서 크게 표시되면 돼.

목록에서 이름을 하나씩 지울 수 있어야 하고, 전체 지우기 버튼도 필요해. 여러 이름을 줄바꿈으로 한꺼번에 붙여 넣는 방법도 있으면 좋겠어.

한 번 뽑힌 사람은 다시 뽑히지 않게 해 줘. 남은 사람이 없으면 그 사실을 화면에 알려 주고, 다시 시작하는 버튼을 보여 줘.

데이터 저장, 데이터베이스, 로그인은 넣지 마. 먼저 계획을 설명한 뒤에 작업해 줘.
</PromptBox>

"남은 사람이 없으면"까지 미리 말해 두는 것이 중요합니다. 이렇게 끝에 도달했을 때 어떻게 할지를 말해 두지 않으면, 아무 반응이 없거나 오류로 멈추는 화면이 나오는 경우가 많습니다.

## 실행하고 확인하기

"실행해서 브라우저로 보여 줘"라고 요청합니다.

<Success>
이름을 넣으면 목록에 쌓이고, 뽑기 버튼을 누르면 한 명이 크게 나옵니다. 같은 사람이 두 번 나오지 않고, 전부 뽑히면 다시 시작하라는 안내가 보입니다.
</Success>

아래 다섯 가지를 직접 해 보세요. 목록을 다루는 앱에서 자주 빠지는 부분입니다.

- 이름을 넣지 않고 추가 버튼을 눌러도 빈 항목이 들어가지 않습니까?
- 같은 이름을 두 번 넣으면 어떻게 됩니까? 그대로 두어도 되는지 판단하세요.
- 목록이 비어 있을 때 뽑기 버튼을 누르면 안내가 나옵니까?
- 이름이 스무 개 넘게 들어가도 목록이 화면 밖으로 넘치지 않습니까?
- 여러 번 뽑았을 때 한쪽으로 치우치지 않습니까?

## 수정하기

교실에서 쓰려면 뽑힌 이름이 화면 멀리에서도 보여야 합니다.

<PromptBox>
뽑힌 이름이 교실 뒷자리에서도 보이게 훨씬 크게 표시해 줘. 이름이 나올 때 잠깐 눈에 띄는 효과를 넣어도 좋아.

이름 목록과 입력 칸은 화면 아래쪽으로 옮겨서 뽑힌 이름을 가리지 않게 해 줘. 기존 동작은 바꾸지 마.
</PromptBox>

## 저장하고 공개하기

[GitHub에 프로젝트 올리기](/code/push-to-github)로 보관하고, [내 웹앱 인터넷에 공개하기](/deployment/first-deploy)로 주소를 만듭니다.

이 앱은 아무 데이터도 저장하지 않으므로 주소를 다른 선생님께 알려 드려도 각자 자기 화면에서 따로 씁니다. 서로의 이름 목록이 섞이지 않습니다.

## 더 해볼 것

- 두 명 이상 한꺼번에 뽑기. 모둠 대표를 정할 때 씁니다.
- 전체를 무작위 순서로 줄 세우기. 발표 순서표가 됩니다.
- 인원수를 정해 모둠으로 나누기.
- 뽑기 결과를 화면 한쪽에 기록으로 남기기. 새로고침하면 사라져도 됩니다.
- 이름 목록을 기억하게 만들기. 이때가 [LocalStorage 붙여보기](/storage/add-localstorage)로 가는 시점입니다.

<TeacherTip>
무작위 뽑기는 학생들이 결과를 아주 진지하게 받아들입니다. 그래서 "정말 무작위인가"를 한번 확인해 보시기 바랍니다. 스무 번쯤 눌러 보고 특정 이름이 유독 자주 나오면 Claude에게 그대로 말하면 됩니다.

한 가지 더 있습니다. 뽑기 결과가 학생에게 부담이 되는 상황이라면, 뽑힌 사람이 다른 사람에게 넘길 수 있는 버튼을 하나 넣어 두세요. 기술적으로는 사소한 기능이지만 교실 분위기는 꽤 달라집니다.
</TeacherTip>
