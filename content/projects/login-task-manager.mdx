## 무엇을 만드나요

로그인해서 쓰는 개인 업무 관리 앱을 만듭니다. Google 계정으로 로그인하면 내가 적은 목록만 보입니다.

옆자리 선생님이 같은 주소로 들어가 로그인하면 그분의 목록이 보입니다. 같은 앱이지만 사람마다 다른 내용이 나옵니다.

[여러 기기에서 쓰는 체크리스트](/projects/shared-checklist)와 결정적으로 다른 점이 여기입니다. 그 앱은 주소를 아는 사람이 모두 같은 목록을 봤습니다.

## 생각하기

| 질문 | 이 앱의 답 | 그래서 |
| --- | --- | --- |
| 데이터를 저장해야 합니까? | 예 | 저장 기능이 필요합니다 |
| 현재 기기에서만 써도 됩니까? | 아니요 | 데이터베이스가 필요합니다 |
| 여러 사람이 같은 데이터를 봐야 합니까? | 아니요 | 각자 자기 것만 봅니다 |
| 변경이 바로바로 보여야 합니까? | 아니요 | 실시간 동기화를 넣지 않습니다 |
| 사용자를 구분해야 합니까? | 예 | 로그인이 필요합니다 |
| 사용자마다 할 수 있는 일이 다릅니까? | 아니요 | 권한 관리는 아직 필요 없습니다 |

다섯 번째에서 로그인이 필요하다는 답이 나왔습니다. 여러 사람이 같은 앱을 쓰되 서로의 내용을 보면 안 되기 때문입니다. 이것이 [로그인이 필요한 이유](/auth/why-login)입니다.

여섯 번째는 "아니요"입니다. 모두가 똑같이 자기 목록을 관리할 뿐, 누구는 되고 누구는 안 되는 일이 없습니다. 그런 구분이 필요해지면 [교사와 학생 역할이 다른 앱](/projects/teacher-student-app)으로 갑니다.

한 가지 더 짚습니다. 로그인을 붙였다고 데이터가 자동으로 안전해지지는 않습니다. 화면에서 남의 목록을 보여 주지 않는 것과, 남의 목록에 실제로 접근할 수 없는 것은 다른 문제입니다. 이 이야기는 [로그인만 붙이면 안전한가요?](/security/login-is-not-enough)에 있습니다.

## 기획하기

누가 쓰나요. 여러 명의 교사가 각자 씁니다. 서로의 내용은 보이지 않습니다.

무엇을 할 수 있어야 하나요. 로그인하고, 자기 업무를 추가하고 완료 표시하고 삭제하고, 로그아웃합니다.

화면에 무엇이 보여야 하나요. 로그인 전에는 로그인 버튼만 있는 화면입니다. 로그인 후에는 내 이름과 목록, 그리고 로그아웃 버튼이 보입니다.

상태 네 가지를 미리 정해 둡니다. 로그인 전, 확인 중, 로그인 성공, 로그인 실패입니다. 특히 확인 중 상태를 빠뜨리면 새로고침할 때마다 로그인 화면이 잠깐 번쩍이는 앱이 됩니다.

## Claude에게 요청하기

[Google 로그인 붙이기](/auth/add-google-login)의 준비 과정을 먼저 마칩니다. Firebase에서 Google 로그인을 켜 두어야 합니다.

<PromptBox>
현재 업무 체크리스트가 Firebase에 저장되고 있어. 지금은 주소를 아는 사람이 모두 같은 목록을 봐.

이제 여러 선생님이 각자 자기 목록만 보게 만들고 싶어. Google 로그인을 붙이고, 로그인한 사용자 자신의 목록만 보이게 해 줘.

데이터는 사용자 ID(uid)를 기준으로 구분해 줘. 이메일 주소를 데이터의 핵심 식별자로 쓰지 마.

로그인 전, 로그인 확인 중, 로그인 성공, 로그인 실패 상태를 각각 화면에 다르게 보여 줘. 로그아웃 버튼도 필요해.

실시간 동기화와 관리자 기능은 필요 없어. 기존 체크리스트 기능과 디자인은 변경하지 마.

먼저 데이터 구조를 어떻게 바꿀지 설명한 다음 작업해 줘.
</PromptBox>

이 요청에서 가장 중요한 줄은 사용자 ID를 기준으로 구분하라는 부분입니다. 이유는 [사용자별 데이터 저장하기](/auth/per-user-data)에 설명되어 있습니다.

작업이 끝나면 보안 규칙도 함께 요청합니다.

<PromptBox>
지금 Firestore 보안 규칙이 어떻게 되어 있는지 확인해 줘.

로그인한 사용자가 자기 데이터에만 접근할 수 있도록 규칙을 만들어 주고, 그 규칙이 무슨 뜻인지 쉬운 말로 설명해 줘.
</PromptBox>

## 실행하고 확인하기

실행한 뒤 로그인해 봅니다. 처음에는 Google 로그인 창이 새로 뜹니다.

<Success>
로그인하면 내 이름이 화면에 보이고, 내가 적은 목록만 나옵니다.

로그아웃하면 목록이 사라지고 로그인 화면으로 돌아갑니다. 새로고침해도 로그인 상태가 유지됩니다.
</Success>

확인할 것이 다섯 가지입니다. 계정 두 개가 있으면 훨씬 확실하게 볼 수 있습니다.

- 다른 계정으로 로그인하면 목록이 비어 있습니까?
- 첫 계정으로 다시 로그인하면 원래 목록이 그대로 돌아옵니까?
- 새로고침했을 때 로그인 화면이 번쩍이지 않습니까?
- 로그아웃한 상태에서 목록 화면 주소로 바로 들어가면 막힙니까?
- Firebase 화면에서 데이터가 사용자별로 나뉘어 저장되어 있습니까?

네 번째와 다섯 번째가 특히 중요합니다. 목록이 섞여 보인다면 [사용자별 데이터가 섞여 보여요](/troubleshooting/user-data-mixed-up)를 보세요.

## 수정하기

로그인이 붙으면 처음 들어온 사람이 무엇을 해야 할지 몰라 멈추는 경우가 많습니다.

<PromptBox>
처음 로그인한 사용자에게 목록이 비어 있는 이유와 무엇을 하면 되는지 안내 문구를 보여 줘.

로그인에 실패했을 때는 왜 실패했는지 알 수 있는 안내와 다시 시도하는 버튼을 보여 줘. 기존 기능은 바꾸지 마.
</PromptBox>
