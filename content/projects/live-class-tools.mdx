## 무엇을 만드나요

지금까지 따로 배운 세 가지를 하나의 앱에 조합합니다. 로그인, 데이터베이스, 실시간 동기화입니다.

이 페이지에서는 실시간 모둠 점수판을 예로 듭니다. 교사가 로그인해서 점수를 주면 교실 앞 화면과 학생 기기 화면에 즉시 반영됩니다. 학생은 로그인 없이 보기만 합니다.

만들고 싶은 도구가 따로 있다면 아래 중에서 골라도 됩니다. 구조는 거의 같습니다.

| 만들 것 | 누가 바꾸나요 | 누가 보나요 |
| --- | --- | --- |
| 모둠 점수판 | 교사 | 학급 전체 |
| 실시간 퀴즈 진행판 | 교사 | 학급 전체 |
| 발표 순서와 진행 상황 | 교사 | 학급 전체 |
| 교실 호출판 | 학생 | 교사 |

## 생각하기

| 질문 | 이 앱의 답 | 그래서 |
| --- | --- | --- |
| 데이터를 저장해야 합니까? | 예 | 저장 기능이 필요합니다 |
| 현재 기기에서만 써도 됩니까? | 아니요 | 데이터베이스가 필요합니다 |
| 여러 사람이 같은 데이터를 봐야 합니까? | 예 | 학급 전체가 같은 화면을 봅니다 |
| 변경이 바로바로 보여야 합니까? | 예 | 실시간 동기화가 필요합니다 |
| 사용자를 구분해야 합니까? | 바꾸는 사람만 | 교사만 로그인합니다 |
| 사용자마다 할 수 있는 일이 다릅니까? | 예 | 교사는 쓰기, 학생은 읽기입니다 |

다섯 번째 답이 지금까지와 다릅니다. 모두가 로그인할 필요는 없고, 점수를 바꾸는 사람만 로그인하면 됩니다.

수업 중에 학생 전원이 로그인하는 데 걸리는 시간을 생각해 보세요. 로그인이 필요한 사람을 최소한으로 줄이는 것도 설계입니다.

대신 조건이 하나 붙습니다. 로그인 없이 보는 화면이 있으므로 이 앱에 개인정보를 넣지 않습니다. 모둠 번호와 점수까지만 저장합니다. 학생 이름이 필요하다고 느껴지면 정말 필요한지 다시 생각해 보세요.

## 기획하기

누가 쓰나요. 교사 한 명이 점수를 바꾸고, 학급 전체가 결과를 봅니다.

무엇을 할 수 있어야 하나요. 교사는 로그인 후 모둠별로 점수를 더하고 뺍니다. 전체 초기화도 필요합니다. 학생과 앞 화면은 보기만 합니다.

화면에 무엇이 보여야 하나요. 모둠 카드가 점수와 함께 나열됩니다. 앞 화면용은 숫자가 크고 버튼이 없습니다. 교사용은 각 모둠 아래에 점수 조정 버튼이 있습니다.

세 가지를 조합할 때는 순서가 중요합니다. 한꺼번에 요청하지 말고 저장, 실시간, 로그인 순서로 하나씩 붙입니다. 문제가 생겼을 때 방금 붙인 것이 원인이라는 것을 알 수 있기 때문입니다.

## Claude에게 요청하기

세 번에 나눠 요청합니다. 각 단계가 잘 되는 것을 확인한 다음 다음 요청으로 넘어갑니다.

<PromptBox>
실시간 모둠 점수판 웹앱을 만들어 줘. 지금은 빈 폴더야.

수업 중에 모둠 점수를 표시하는 화면이야. 모둠이 여섯 개 있고 각 모둠에 점수가 있어. 점수를 1점씩 더하고 빼는 버튼과 전체 초기화 버튼이 필요해.

저장할 데이터는 모둠 번호와 점수까지만이야. 학생 이름이나 개인정보는 저장하지 마.

Firebase에 저장하고, 한 화면에서 점수를 바꾸면 같은 주소를 연 다른 모든 화면에 새로고침 없이 바로 반영되게 해 줘. 설정값은 환경변수로 관리해 줘.

로그인은 이번 요청에서 넣지 마. 먼저 데이터 구조를 설명한 다음 작업해 줘.
</PromptBox>

여기까지 확인한 뒤 교사만 점수를 바꿀 수 있게 만듭니다.

<PromptBox>
이제 Google 로그인을 붙여 줘. 로그인한 사용자만 점수를 더하고 빼고 초기화할 수 있어야 해.

로그인하지 않은 사람도 점수판을 볼 수는 있어야 해. 로그인하지 않은 화면에서는 점수 조정 버튼이 아예 보이지 않게 해 줘.

교실 앞 화면에 띄우는 보기 전용 화면도 하나 만들어 줘. 숫자만 크게 보이고 버튼은 없는 화면이야.

Firestore 보안 규칙도 함께 만들어 줘. 누구나 읽을 수는 있지만 로그인한 사용자만 쓸 수 있어야 해. 규칙이 무슨 뜻인지 쉬운 말로 설명해 줘.

기존 기능과 실시간 동작은 바꾸지 마.
</PromptBox>

## 실행하고 확인하기

브라우저 창을 세 개 띄워 놓고 확인합니다. 하나는 로그인한 교사 화면, 하나는 로그인하지 않은 학생 화면, 하나는 앞 화면용입니다.

<Success>
교사 화면에서 점수를 올리면 나머지 두 화면의 숫자가 곧바로 함께 올라갑니다.

로그인하지 않은 화면에는 점수 조정 버튼이 보이지 않습니다.
</Success>

확인할 것이 다섯 가지입니다.

- 창 세 개의 숫자가 항상 같습니까?
- 로그인하지 않은 상태에서 점수를 바꾸려 하면 실제로 차단됩니까?
- 점수를 빠르게 여러 번 눌러도 숫자가 어긋나지 않습니까?
- 인터넷이 잠깐 끊겼다 돌아오면 숫자가 다시 맞춰집니까?
- 창을 여러 번 열고 닫아도 화면이 느려지지 않습니까?

두 번째는 버튼이 안 보이는 것과 다른 문제입니다. 확인 방법은 [로그인만 붙이면 안전한가요?](/security/login-is-not-enough)에 있습니다.

## 수정하기

수업에서 쓰려면 앞 화면이 멀리서도 읽혀야 합니다.

<PromptBox>
앞 화면용 보기 전용 화면의 점수 숫자를 교실 뒷자리에서도 읽히게 훨씬 크게 해 줘.

점수가 바뀔 때 그 모둠 카드가 잠깐 눈에 띄게 표시되면 좋겠어. 어느 모둠이 방금 점수를 받았는지 학생들이 바로 알 수 있게.

교사 화면과 기존 기능은 바꾸지 마.
</PromptBox>
