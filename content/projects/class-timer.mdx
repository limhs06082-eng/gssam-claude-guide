## 무엇을 만드나요

교실 앞 화면에 띄워 놓고 쓰는 타이머를 만듭니다. 남은 시간이 멀리서도 보일 만큼 크게 나오고, 시작과 멈춤과 초기화를 버튼으로 합니다.

앞의 소개 홈페이지와 다른 점이 하나 있습니다. 이 앱은 화면이 스스로 바뀝니다. 숫자가 1초마다 줄어들고, 버튼을 누르면 상태가 달라집니다. 무언가 저장하지는 않지만 화면이 움직이는 첫 앱입니다.

## 생각하기

먼저 저장이 필요한지부터 봅니다.

| 질문 | 이 앱의 답 | 그래서 |
| --- | --- | --- |
| 데이터를 저장해야 합니까? | 아니요 | 저장 기능이 필요 없습니다 |
| 여러 사람이 같은 데이터를 봐야 합니까? | 아니요 | 데이터베이스가 필요 없습니다 |
| 변경이 바로바로 보여야 합니까? | 아니요 | 실시간 동기화가 필요 없습니다 |
| 사용자를 구분해야 합니까? | 아니요 | 로그인이 필요 없습니다 |

여기서 헷갈리기 쉬운 곳이 세 번째 줄입니다. 숫자가 1초마다 바뀌니까 실시간 기능이 필요하다고 생각하기 쉽습니다.

실시간 동기화는 다른 사람의 화면과 맞추는 기능입니다. 이 타이머는 교실 화면 한 대에서 혼자 돌아가면 됩니다. 그러니 필요하지 않습니다. 이 구분은 [실시간 기능이 필요 없는 경우](/realtime/when-not-to-use-realtime)에서 자세히 다룹니다.

시간 설정을 기억해 두면 편하지 않을까 하는 생각도 듭니다. 그것은 저장이 필요한 일입니다. 지금은 넣지 말고, 만들어 써 본 뒤에 정말 불편하면 그때 붙이세요.

## 기획하기

누가 쓰나요. 수업하는 교사입니다. 교실 앞 화면에 띄워 두고 학생들이 함께 봅니다.

무엇을 할 수 있어야 하나요. 시간을 정하고, 시작하고, 멈추고, 처음으로 되돌립니다.

화면에 무엇이 보여야 하나요. 남은 시간이 화면 대부분을 차지할 만큼 큰 숫자로 나옵니다. 그 아래에 버튼 세 개가 있습니다. 시간이 다 되면 화면에서 바로 알아볼 수 있어야 합니다.

한 가지 더 정합니다. 자주 쓰는 시간이 몇 분인지 생각해 보세요. 3분, 5분, 10분처럼 두세 개를 정해 두면 매번 숫자를 입력하지 않아도 됩니다.

## Claude에게 요청하기

새 폴더를 만들어 Claude Code 앱에서 엽니다. 타이머는 소개 홈페이지와 다른 프로젝트이므로 폴더를 따로 씁니다.

<PromptBox>
수업용 타이머 웹앱을 만들어 줘. 지금은 빈 폴더야.

교실 앞 화면에 띄워 놓고 학생들과 같이 보는 용도야. 남은 시간이 멀리서도 보이게 화면 가운데에 아주 크게 표시해 줘.

시작, 멈춤, 초기화 버튼이 필요해. 3분, 5분, 10분을 한 번에 고르는 버튼도 넣어 줘. 직접 분을 입력하는 칸도 있으면 좋겠어.

시간이 0이 되면 숫자 색이 바뀌고 화면에서 바로 알 수 있게 해 줘. 소리는 넣지 마.

데이터 저장, 데이터베이스, 로그인은 필요 없어. 먼저 어떻게 만들지 계획을 설명한 뒤에 작업해 줘.
</PromptBox>

소리를 넣지 말라고 한 이유가 있습니다. 브라우저는 소리 재생을 막는 경우가 많아서, 처음부터 넣으면 안 되는 이유를 찾느라 시간을 쓰게 됩니다. 화면이 먼저 잘 돌아간 다음에 붙이는 편이 낫습니다.

## 실행하고 확인하기

"실행해서 브라우저로 보여 줘"라고 요청합니다. 방법은 [프로그램 실행하기](/code/run-it)에 있습니다.

<Success>
큰 숫자가 화면 가운데에 보이고, 시작 버튼을 누르면 1초마다 줄어듭니다. 멈춤을 누르면 그 자리에 멈추고, 초기화를 누르면 처음 시간으로 돌아갑니다.
</Success>

타이머는 눈으로 대충 보면 잘 되는 것처럼 보입니다. 아래 네 가지를 직접 눌러 보세요.

- 시작을 두 번 연속 누르면 숫자가 두 배로 빨리 줄지 않습니까?
- 멈춘 상태에서 시작을 다시 누르면 멈춘 시간부터 이어집니까?
- 0이 된 뒤에도 계속 줄어들어 음수가 되지 않습니까?
- 5분 버튼을 누른 뒤 초기화하면 5분으로 돌아갑니까, 아니면 처음 값으로 돌아갑니까?

두 번째와 세 번째는 실제로 자주 나오는 문제입니다. 발견하면 그대로 Claude에게 말하면 됩니다.

## 수정하기

교실에서 쓰려면 화면이 멀리서도 읽혀야 합니다. 크기부터 손봅니다.

<PromptBox>
교실 앞 화면에 띄워 놓고 쓸 거야. 뒷자리에서도 읽히도록 남은 시간 숫자를 지금보다 훨씬 크게 해 줘.

버튼은 지금 크기를 유지하고, 화면 아래쪽에 두어서 숫자를 가리지 않게 해 줘. 기존 동작은 바꾸지 마.
</PromptBox>

크기를 바꾸면 휴대폰 화면에서 숫자가 잘리는 경우가 있습니다. 브라우저 창을 좁게 줄여 확인해 보고, 잘린다면 [모바일 화면 수정하기](/code/fix-mobile)를 참고해 이어서 요청하세요.

## 더 해볼 것

- 시간이 다 되었을 때 화면 전체 색이 바뀌게 하기.
- 남은 시간을 막대로도 보여 주기. 숫자를 못 읽는 저학년에게 유용합니다.
- 모둠 활동용으로 타이머 두 개를 나란히 놓기.
- 자주 쓰는 시간 버튼을 내 수업에 맞게 바꾸기.
- 다 쓰고 나면 시간 설정을 기억하게 만들기. 이때가 [LocalStorage 붙여보기](/storage/add-localstorage)로 넘어갈 시점입니다.

## G쌤 팁

<TeacherTip>
타이머는 만들기 쉬워 보이지만 실제로 교실에서 써 보면 고칠 것이 계속 나옵니다. 숫자가 작다, 버튼이 헷갈린다, 끝난 걸 못 알아본다 같은 것들입니다.

그래서 이 프로젝트를 두 번째에 두었습니다. 한 번 만들고 실제로 써 보고 고치는 흐름을 몸에 익히기에 가장 좋은 앱입니다.

고칠 것이 보이면 그날 바로 한 가지만 고치세요. 열 가지를 모아서 한 번에 요청하면 무엇 때문에 화면이 이상해졌는지 찾기 어려워집니다.
</TeacherTip>
