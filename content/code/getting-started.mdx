## 이것만 알아두세요

Claude Code는 Claude 데스크톱 앱 안에서 씁니다. 웹 브라우저가 아니라 컴퓨터에 설치하는 앱입니다.

준비할 것은 세 가지입니다. 데스크톱 앱, Claude 계정, 그리고 빈 폴더 하나입니다.

## 직접 해봅시다

<Steps>
<Step title="Claude 데스크톱 앱을 설치합니다">
claude.ai에서 데스크톱 앱 내려받기 안내를 찾아 Windows용 또는 Mac용을 설치합니다.

이미 브라우저에서 Claude를 쓰고 있어도 데스크톱 앱은 따로 설치해야 합니다. Code 영역은 데스크톱 앱에서 씁니다.
</Step>
<Step title="앱을 열고 로그인합니다">
평소 쓰던 계정으로 로그인합니다. 계정이 없다면 이메일이나 Google 계정으로 무료로 만들 수 있습니다.
</Step>
<Step title="Code 영역을 엽니다">
앱 안에서 Code 영역으로 이동합니다. Chat, Cowork와 나란히 있는 작업 방식 중 하나입니다.

메뉴 이름과 모양은 버전에 따라 조금씩 다를 수 있습니다. Code라는 이름을 찾으면 됩니다.
</Step>
<Step title="빈 폴더를 하나 만들어 둡니다">
문서 폴더 안에 `my-first-site` 같은 이름으로 새 폴더를 만듭니다. 아직 아무 파일도 없어도 됩니다.

폴더 이름과 위치를 정하는 방법은 [프로젝트 폴더란?](/code/project-folder)에 자세히 나옵니다.
</Step>
<Step title="그 폴더를 작업 폴더로 지정합니다">
Code 영역에서 폴더를 여는 메뉴를 찾아 방금 만든 폴더를 고릅니다.

Claude Code는 이 폴더 안에서만 일합니다. 폴더 밖의 파일은 건드리지 않습니다.
</Step>
<Step title="대화창에 첫 인사를 보냅니다">
아래 문장을 그대로 붙여 넣고 보냅니다. 아직 아무것도 만들지 않는 안전한 요청입니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
안녕. 지금 이 폴더에 어떤 파일이 있는지 알려 줘. 아직 아무것도 만들거나 고치지 말고, 확인만 해 줘.
</PromptBox>

## 이렇게 나오면 성공입니다

<Success>
"이 폴더는 비어 있습니다" 같은 답이 돌아옵니다. 폴더 이름이 내가 만든 이름과 같은지 확인하세요.

이 답을 받았다면 Claude가 내 폴더를 제대로 보고 있다는 뜻입니다. 이제 무엇이든 만들어 달라고 할 수 있습니다.
</Success>

## 잘 안 된다면

<Troubleshoot>
<Problem title="앱에 Code 영역이 보이지 않아요">
Code 기능은 요금제나 지역, 앱 버전에 따라 제공 여부가 다를 수 있습니다. 앱을 최신 버전으로 업데이트한 뒤 다시 확인하고, 그래도 보이지 않으면 공식 안내를 확인하세요.
</Problem>
<Problem title="폴더를 고르는 창에서 내 폴더를 못 찾겠어요">
폴더를 바탕화면이 아니라 문서 폴더 안에 만들면 찾기 쉽습니다. 위치가 기억나지 않으면 [프로젝트 폴더가 어디 있는지 모르겠어요](/troubleshooting/cant-find-project-folder)를 보세요.
</Problem>
<Problem title="답이 오지 않고 계속 기다리기만 해요">
인터넷 연결을 확인하고, 대화창을 새로 시작해 같은 문장을 다시 보내 보세요. 앱을 껐다 켜는 것만으로 풀리는 경우도 많습니다.
</Problem>
</Troubleshoot>
