## 이것만 알아두세요

드디어 만드는 단계입니다. 앞에서 정한 계획을 그대로 요청으로 옮기면 됩니다.

요청을 보내면 Claude가 폴더 안에 파일을 만들기 시작합니다. 몇 분 걸릴 수 있으니 기다리세요.

## 요청에 넣을 네 가지

좋은 요청에는 특별한 형식이 없습니다. 다만 이 네 가지가 들어 있으면 결과가 훨씬 정확합니다.

- 무엇을 만드는지: "한 페이지짜리 개인 소개 홈페이지"
- 담을 내용: 이름, 소개 문장, 좋아하는 것, 연락 방법
- 어떤 사람이 볼지: "학부모님이 보실 페이지"
- 지금 필요 없는 것: "로그인이나 데이터 저장은 없어도 돼"

마지막 항목을 빠뜨리면 요청하지 않은 기능이 붙어 나오는 경우가 있습니다.

## 직접 해봅시다

<Steps>
<Step title="작업 폴더를 확인합니다">
소개 홈페이지를 만들 폴더가 열려 있는지 봅니다.
</Step>
<Step title="아래 문장을 내 내용으로 바꿔 보냅니다">
이름과 소개는 내 것으로 바꿉니다. 마지막 문장은 그대로 두세요.
</Step>
<Step title="허락을 묻는 창이 뜨면 읽고 허락합니다">
어떤 파일을 만들려는지 읽어 봅니다. 내 프로젝트 폴더 안의 파일이면 허락합니다.
</Step>
<Step title="작업이 끝날 때까지 기다립니다">
작업 내용 영역에 파일 이름이 하나씩 올라옵니다. 중간에 창을 닫지 마세요.
</Step>
<Step title="파일 목록을 확인합니다">
폴더에 파일이 새로 생겼는지 봅니다. 보통 두세 개가 생깁니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
앞에서 이야기한 계획대로 개인 소개 홈페이지를 만들어 줘. 내 이름은 김하늘, 초등학교 6학년 담임이야. 짧은 소개 세 문장, 좋아하는 것 세 가지, 이메일 연락 방법을 넣어 줘.

로그인이나 데이터 저장 기능은 넣지 마. 브라우저에서 파일을 열면 바로 보이는 간단한 형태로 만들어 줘. 다 만든 뒤에 어떤 파일을 만들었는지 쉬운 말로 알려 줘.
</PromptBox>

## 이렇게 나오면 성공입니다

<Success>
폴더 안에 파일이 두세 개 생기고, 각 파일이 무슨 역할인지 설명이 돌아옵니다.

아직 화면을 보지 못했어도 성공입니다. 화면 확인은 [프로그램 실행하기](/code/run-it)에서 합니다.

내용이 조금 달라도 지금 고치지 마세요. 먼저 눈으로 보고 나서 고치는 편이 훨씬 쉽습니다.
</Success>

## 잘 안 된다면

<Troubleshoot>
<Problem title="허락 창이 무슨 말인지 모르겠어요">
허락하지 말고 대화창에 "방금 뭘 하려는 건지 쉬운 말로 설명해 줘"라고 물어보세요. 설명을 듣고 결정하면 됩니다.
</Problem>
<Problem title="한참 기다려도 끝나지 않아요">
작업 내용 영역이 계속 움직이고 있으면 정상입니다. 완전히 멈춰 있다면 "지금 어디까지 됐어?"라고 물어보세요.
</Problem>
<Problem title="내가 말하지 않은 기능이 잔뜩 들어갔어요">
"방문자 수 기능은 빼 줘. 나머지 내용과 디자인은 그대로 둬"라고 이어서 말하면 됩니다. 처음부터 다시 만들 필요가 없습니다.
</Problem>
<Problem title="파일이 엉뚱한 곳에 생긴 것 같아요">
"방금 만든 파일들이 정확히 어느 폴더에 있는지 경로를 알려 줘"라고 물어보세요.
</Problem>
</Troubleshoot>
