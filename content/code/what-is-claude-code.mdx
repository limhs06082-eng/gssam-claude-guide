## 이것만 알아두세요

Claude Code는 Claude 데스크톱 앱 안에 있는 영역입니다. 내 컴퓨터의 폴더 하나를 정해 주면, 그 안의 파일을 직접 읽고 만들고 고칩니다.

Chat에서도 코드 이야기를 할 수 있습니다. 차이는 결과가 어디에 남는가입니다. Chat은 화면에 답을 보여 주고, Code는 내 폴더에 파일을 만들어 둡니다.

## 쉽게 생각하면

<Analogy>
Chat은 전화로 조언을 듣는 것과 같습니다. "이렇게 해 보세요"라는 말을 듣고, 실제로 하는 사람은 나입니다.

Code는 그 사람이 내 방에 와서 같이 작업하는 것과 같습니다. 서랍을 열어 서류를 보고, 새 서류를 만들고, 고친 자리를 보여 줍니다.

대신 내 방에 들어오는 것이므로 어느 방인지 먼저 알려 줘야 합니다. 그것이 프로젝트 폴더입니다.
</Analogy>

## Claude Code로 할 수 있는 일

말로 요청할 수 있는 일은 다음과 같습니다.

- 새 프로그램을 처음부터 만들기
- 이미 있는 파일을 고치기
- 만든 것을 실행해서 화면으로 보여 주기
- 오류가 났을 때 원인을 찾고 고치기
- 지금까지의 작업을 기록으로 저장하기
- 완성한 것을 인터넷에 올릴 준비를 하기

전부 대화창에 한국어로 부탁하면 됩니다. 명령어를 외울 필요가 없습니다.

다만 계정에 로그인하는 일은 사용자가 직접 해야 합니다. GitHub나 배포 서비스에 로그인해야 하는 순간이 오면 브라우저 창에서 직접 승인하게 됩니다.

## 파일을 고치기 전에 물어봅니다

Claude Code는 파일을 바꾸거나 명령을 실행하기 전에 허락을 묻는 경우가 있습니다.

얼마나 자주 물어볼지는 **권한 모드**로 정합니다. 대화창의 보내기 버튼 옆에 있는 선택 메뉴입니다. **수동**(Manual)은 파일을 고치거나 명령을 실행하기 전에 매번 묻고, **자동**(Auto)은 묻지 않고 계속 진행합니다.

앱 버전과 계정에 따라 처음부터 자동으로 되어 있을 수 있습니다. 처음에는 수동으로 바꿔 두세요. 한 번 고르면 그 폴더에서는 다음에도 그대로 유지됩니다.

수동으로 두면 물음이 자주 뜹니다. 귀찮게 여기지 말고 하나씩 읽어 보세요. 무엇을 하려는지 알 수 있고, 원하지 않는 작업이면 그 자리에서 막을 수 있습니다.

익숙해지면 어떤 요청이 어떤 작업으로 이어지는지 감이 잡힙니다. 그때 자동으로 바꿔도 늦지 않습니다. 메뉴에는 편집 허용, 계획 같은 다른 선택지도 보이는데, 지금은 몰라도 됩니다.

<Warning>
Claude Code는 프로젝트 폴더 안의 파일을 실제로 바꿉니다. 화면 속 미리보기가 아니라 내 컴퓨터의 파일입니다.

그래서 이미 중요한 자료가 들어 있는 폴더를 프로젝트 폴더로 고르지 마세요. 연습은 비어 있는 새 폴더에서 시작합니다.
</Warning>

## 무엇을 먼저 물어볼까요

Claude Code를 처음 열면 무슨 말을 해야 할지 막막합니다. 이렇게 시작하면 됩니다.

- "이 폴더에 뭐가 들어 있는지 알려 줘."
- "이런 걸 만들고 싶은데 어떻게 하면 좋을지 계획만 먼저 알려 줘."
- "방금 만든 걸 실행해서 보여 줘."

전부 평소 말투 그대로입니다. 특별한 형식은 없습니다.

한 가지만 기억하세요. 아직 파일을 만들고 싶지 않을 때는 "아직 파일은 만들지 마"를 붙입니다. 이 한 줄이 원치 않는 작업을 막아 줍니다.

## Cowork와는 어떻게 다른가요

Cowork는 문서와 자료를 정리해 결과물을 만들어 주는 쪽입니다. 보고서, 표, 요약본처럼 사람이 읽을 파일이 나옵니다.

Code는 동작하는 프로그램을 만드는 쪽입니다. 결과물은 사람이 읽는 문서가 아니라, 브라우저에서 열리고 버튼이 눌리는 화면입니다.

둘 다 폴더를 정해 주고 일을 맡긴다는 점은 같습니다. 무엇을 만들고 싶은가로 고르면 됩니다.

## G쌤 팁

<TeacherTip>
"코드"라는 말 때문에 겁먹을 필요는 없습니다. 저는 이 영역을 그냥 "만들어 주는 창"이라고 생각하고 씁니다.

실제로 제가 하는 일은 폴더를 하나 고르고, 원하는 것을 한국어로 적고, 나온 화면을 눌러 보는 것이 전부입니다.
</TeacherTip>
