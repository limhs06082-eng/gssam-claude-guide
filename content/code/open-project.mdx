## 이것만 알아두세요

프로젝트는 폴더 안에 그대로 남아 있습니다. 앱을 껐다 켜도, 컴퓨터를 다시 시작해도 사라지지 않습니다.

다시 시작하는 방법은 처음과 같습니다. 그 폴더를 작업 폴더로 열면 됩니다.

## 쉽게 생각하면

<Analogy>
어제 쓰다 만 서류를 서랍에서 다시 꺼내는 것과 같습니다.

서류는 그대로지만, 어디까지 썼는지는 기억이 흐릿합니다. 그래서 다시 읽어 보고 시작합니다.

Claude에게도 같은 부탁을 할 수 있습니다. "지금까지 뭘 만들었는지 정리해 줘"라고요.
</Analogy>

## 직접 해봅시다

<Steps>
<Step title="Claude 데스크톱 앱을 열고 Code 영역으로 갑니다">
새 대화를 시작해도 되고, 이전 대화가 남아 있으면 그것을 이어서 써도 됩니다.
</Step>
<Step title="예전에 쓰던 폴더를 작업 폴더로 엽니다">
최근에 연 폴더 목록이 보이면 거기서 고릅니다. 보이지 않으면 폴더를 여는 메뉴에서 직접 찾아 고릅니다.
</Step>
<Step title="작업 폴더 이름을 확인합니다">
화면에 표시된 폴더 이름이 내가 이어서 하려는 프로젝트가 맞는지 봅니다.
</Step>
<Step title="지금 상태를 물어봅니다">
아래 문장을 붙여 넣습니다. 파일을 고치지 않고 정리만 해 달라는 요청입니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
이 프로젝트가 어떤 프로그램인지, 지금 어디까지 만들어져 있는지 요약해 줘. 파일은 아직 고치지 말고 설명만 해 줘.
</PromptBox>

## 이렇게 나오면 성공입니다

<Success>
"개인 소개 홈페이지이고, 이름과 소개 문단, 좋아하는 것 목록이 들어 있습니다" 같은 요약이 돌아옵니다.

내가 기억하는 내용과 맞는지 확인하세요. 맞다면 이어서 작업하면 됩니다.
</Success>

## 대화 기록은 어떻게 되나요

대화 기록과 프로젝트 파일은 별개입니다.

파일은 폴더에 그대로 남습니다. 대화 기록은 남아 있을 수도 있고, 새 대화로 시작하게 될 수도 있습니다.

새 대화로 시작해도 문제가 되지 않습니다. Claude는 폴더 안의 파일을 다시 읽고 지금 상태를 파악합니다. 위의 요약 요청이 그 역할을 합니다.

다만 "아까 그거 다시 해 줘"처럼 앞 대화를 가리키는 말은 통하지 않을 수 있습니다. 무엇을 원하는지 다시 한 문장으로 적어 주세요.

## 여러 프로젝트를 오갈 때

프로젝트가 두세 개가 되면 폴더를 착각하기 쉽습니다.

가장 흔한 실수는 A 프로젝트를 열어 놓고 B 프로젝트에 할 요청을 보내는 것입니다. 엉뚱한 폴더에 파일이 생깁니다.

그래서 요청을 보내기 전에 작업 폴더 이름을 한 번 보는 습관이 좋습니다. 3초면 됩니다.

프로젝트마다 다른 폴더를 쓰고, 폴더 이름을 알아보기 쉽게 지어 두면 이런 착각이 크게 줄어듭니다.

## 잘 안 된다면

<Troubleshoot>
<Problem title="폴더를 어디에 뒀는지 모르겠어요">
파일 탐색기(Windows)나 Finder(Mac)의 검색창에 폴더 이름을 넣어 찾습니다. 방법은 [프로젝트 폴더가 어디 있는지 모르겠어요](/troubleshooting/cant-find-project-folder)에 있습니다.
</Problem>
<Problem title="요약 내용이 내가 만든 것과 달라요">
다른 프로젝트 폴더를 열었을 가능성이 큽니다. 작업 폴더 이름을 다시 확인하세요.
</Problem>
</Troubleshoot>
