## 이것만 알아두세요

Claude Code 화면은 크게 세 가지를 보여 줍니다. 내가 말하는 곳, Claude가 만든 파일, 그리고 만든 것을 확인하는 화면입니다.

이름을 다 외울 필요는 없습니다. 어떤 영역이 무슨 일을 하는지만 알면 됩니다.

## 화면에서 찾아보세요

<ScreenGuide>
1. **작업 폴더 표시** — 지금 어느 폴더에서 일하고 있는지 보여 줍니다. 여러 프로젝트를 오갈 때 가장 먼저 확인할 곳입니다.
2. **대화창** — 요청을 적는 곳입니다. Chat과 똑같이 한국어로 적으면 됩니다.
3. **작업 내용 영역** — Claude가 지금 무엇을 하고 있는지, 어떤 파일을 만들고 고쳤는지 순서대로 보여 줍니다.
4. **파일 목록** — 폴더 안에 있는 파일들입니다. 새 파일이 생기면 여기에 나타납니다.
5. **미리보기 화면** — 만든 웹페이지가 실제로 어떻게 보이는지 앱 안에서 확인하는 브라우저 화면입니다.
6. **터미널 화면** — 프로그램을 실행할 때 나오는 글자들이 지나가는 곳입니다. 여기에 직접 명령을 칠 일은 없습니다.
7. **권한 모드 선택** — 대화창의 보내기 버튼 옆에 있는 작은 선택 메뉴입니다. **수동**(Manual), **자동**(Auto) 같은 이름이 보입니다. Claude가 작업 전에 물어볼지를 여기서 정합니다.
</ScreenGuide>

영역의 배치와 이름은 앱 버전에 따라 달라질 수 있습니다. 위치보다 역할로 기억해 두세요.

## 가장 많이 보게 될 곳

실제로 쓰다 보면 시선이 두 곳에 머뭅니다.

첫째는 대화창입니다. 요청은 전부 여기에서 시작합니다.

둘째는 작업 내용 영역입니다. Claude가 파일을 만들 때마다 한 줄씩 올라옵니다. 여기를 보면 "지금 뭘 하고 있는지 모르겠다"는 답답함이 크게 줄어듭니다.

## 허락을 묻는 창

작업 도중에 "이 파일을 수정해도 될까요" 같은 확인이 뜰 수 있습니다.

이 창은 막는 장치가 아니라 알려 주는 장치입니다. 어떤 파일에 무슨 일을 하려는지 읽고, 괜찮으면 허락합니다.

읽었을 때 뜻을 모르겠다면 허락하지 말고 대화창에 "방금 뭘 하려는 건지 쉽게 설명해 줘"라고 물어보세요.

이 창이 한 번도 뜨지 않는다면 권한 모드가 자동으로 되어 있는 것입니다. 보내기 버튼 옆의 권한 모드 선택에서 수동을 고르면 작업 전에 매번 물어봅니다. 처음에는 수동을 권합니다.

## 화면을 다 이해하지 않아도 됩니다

처음 화면을 열면 낯선 영역이 여럿 보입니다. 전부 알아야 시작할 수 있는 것은 아닙니다.

지금 필요한 것은 두 가지뿐입니다. 요청을 적는 곳과, 결과를 보는 곳입니다.

나머지는 쓰다 보면 자연스럽게 필요해집니다. 파일 목록은 파일이 여러 개가 되었을 때, 터미널 화면은 실행이 잘 안 될 때 눈에 들어옵니다.

화면 구성이 바뀌어 당황했다면 대화창에 물어봐도 됩니다. "지금 만든 웹페이지를 어디서 미리 볼 수 있는지 알려 줘"처럼 물으면 안내해 줍니다.

## 자주 하는 착각

<Note>
미리보기 화면에 아무것도 안 보인다고 해서 실패한 것이 아닙니다.

아직 아무 파일도 만들지 않았거나, 만든 파일을 아직 실행하지 않았을 수 있습니다. 실행하는 방법은 [프로그램 실행하기](/code/run-it)에서 다룹니다.
</Note>

## G쌤 팁

<TeacherTip>
화면을 처음 봤을 때 저는 영역이 너무 많아서 어디를 봐야 할지 몰랐습니다.

그때 도움이 된 방법은 대화창만 보고 시작하는 것이었습니다. 나머지 영역은 필요할 때 자연스럽게 눈에 들어옵니다.

지금 화면이 낯설어도 괜찮습니다. 다음 페이지부터는 실제로 무언가를 만들면서 각 영역을 하나씩 쓰게 됩니다.
</TeacherTip>
