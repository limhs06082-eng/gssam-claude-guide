코딩을 배운 적이 없어도 프로그램을 만들 수 있습니다. 이 과정에서는 Claude Code 앱에게 한국어로 말을 걸어 나만의 웹페이지를 하나 완성합니다. 터미널을 열 일도, 명령어를 외울 일도 없습니다.

함께 만들 첫 결과물은 나를 소개하는 한 페이지 홈페이지입니다. 무엇을 만들지 정하는 것부터 시작해 Claude에게 요청하고, 만들어진 화면을 브라우저에서 확인하고, 문장과 색과 버튼을 하나씩 고쳐 나갑니다. 완성한 뒤에는 인터넷 보관함인 GitHub에 올려 안전하게 보관하는 데까지 갑니다.

중간에 오류가 나는 것도 과정의 일부입니다. 이 과정에는 오류 메시지를 Claude에게 보여 주는 방법과, 수정이 잘못됐을 때 이전 상태로 돌아가는 방법이 따로 들어 있습니다. 무언가 망가뜨릴까 봐 걱정하지 않아도 됩니다.
