## 이것만 알아두세요

기능은 한 번에 하나씩만 추가합니다. 두 개를 같이 부탁하면 문제가 생겼을 때 원인을 찾기 어렵습니다.

추가하기 전에 지금 상태가 잘 되는지 확인하고, 추가한 뒤에 다시 확인합니다.

## 쉽게 생각하면

<Analogy>
요리에 재료를 넣는 것과 같습니다.

소금과 간장을 한꺼번에 넣고 맛이 이상하면 무엇 때문인지 알 수 없습니다.

하나 넣고 맛보고, 또 하나 넣고 맛보면 원인이 분명해집니다. 기능도 그렇게 더합니다.
</Analogy>

## 어떤 기능을 더할까요

소개 홈페이지에 어울리는 작은 기능입니다.

- 소개 내용을 접었다 펴는 기능
- 오늘 날짜를 화면에 보여 주는 기능
- 좋아하는 것 목록에 그림 문자나 아이콘을 붙이는 기능

이번에는 접었다 펴는 기능을 만들어 봅니다. 화면이 길어졌을 때 실제로 쓸모가 있습니다.

## 직접 해봅시다

<Steps>
<Step title="지금 화면이 잘 되는지 확인합니다">
새로고침해서 내용이 다 보이고 버튼도 눌리는지 봅니다. 고장난 상태에서 기능을 더하면 원인이 섞입니다.
</Step>
<Step title="지금까지의 작업을 저장해 둡니다">
"여기까지 저장해 둬"라고 부탁합니다. 되돌릴 수 있는 지점이 생깁니다. 이 저장이 무엇인지는 [Git이란?](/code/what-is-git)에서 다룹니다.
</Step>
<Step title="기능 하나만 요청합니다">
아래 문장을 보냅니다.
</Step>
<Step title="새로고침하고 직접 눌러 봅니다">
접히는지, 다시 펴지는지 두 번 다 확인합니다.
</Step>
<Step title="기존 기능도 확인합니다">
앞에서 만든 이메일 버튼이 여전히 동작하는지 눌러 봅니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
"좋아하는 것" 목록을 접었다 펼 수 있게 해 줘. 처음에는 접혀 있고, 제목을 누르면 펼쳐지고 다시 누르면 접히면 좋겠어.

이 기능만 추가하고, 나머지 내용과 색상, 버튼은 그대로 둬.
</PromptBox>

## 이렇게 나오면 성공입니다

<Success>
제목을 누르면 목록이 펼쳐지고, 한 번 더 누르면 접힙니다.

앞에서 만든 이메일 버튼도 그대로 동작합니다. 새 기능이 기존 기능을 건드리지 않았다는 뜻입니다.
</Success>

## 확인해야 할 두 가지

새 기능을 넣은 뒤에는 두 가지를 봅니다.

첫째, 새 기능이 되는가입니다. 눌러 보고, 두 번 눌러 보고, 새로고침한 뒤에도 되는지 봅니다.

둘째, 원래 되던 것이 여전히 되는가입니다. 이 확인을 빠뜨리는 경우가 많습니다.

원래 되던 것이 안 되면 [Claude가 잘못 수정했을 때](/code/when-claude-breaks-things)로 가세요.

## 잘 안 된다면

<Troubleshoot>
<Problem title="새 기능이 동작하지 않아요">
"제목을 눌러도 목록이 펼쳐지지 않아. 눌렀을 때 펼쳐지도록 고쳐 줘"라고 증상 그대로 말하세요.
</Problem>
<Problem title="기능은 되는데 다른 것이 망가졌어요">
"방금 수정 전으로 되돌려 줘"라고 먼저 말하고, 되돌린 뒤에 요청을 더 작게 나누어 다시 부탁합니다.
</Problem>
<Problem title="한 번에 여러 기능을 부탁했더니 엉켰어요">
"방금 수정 전으로 되돌려 줘"라고 한 뒤, 기능을 하나씩 다시 요청하세요. 한 번에 하나가 결국 더 빠릅니다.
</Problem>
</Troubleshoot>

## G쌤 팁

<TeacherTip>
기능을 더하기 전에 저장 지점을 만드는 습관이 가장 큰 도움이 됩니다.

저장해 두면 마음 놓고 시도할 수 있습니다. 잘 안 되면 그 지점으로 돌아가면 그만이니까요.

이 저장을 자동으로 해 주는 도구가 뒤에 나오는 Git입니다. 지금은 "여기까지 저장해 둬"라고 말하는 것만 기억하세요.
</TeacherTip>
