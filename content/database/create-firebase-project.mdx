## 이것만 알아두세요

여기서 하는 일은 인터넷에 내 데이터 보관함을 하나 만드는 것입니다.

만들고 나면 그 보관함을 가리키는 설정값 몇 줄이 나옵니다. 그 값을 Claude Code에 전달하면 내 앱과 보관함이 연결됩니다.

## 시작하기 전에

Google 계정이 필요합니다. 학교 계정이든 개인 계정이든 상관없지만, 나중에도 계속 쓸 계정으로 하세요.

브라우저에서 Firebase 콘솔(console.firebase.google.com)을 엽니다. Claude Code 앱은 잠시 그대로 두고 브라우저에서 작업합니다.

<Note>
Firebase 화면은 제품 업데이트에 따라 바뀔 수 있습니다. 버튼 이름이 아래 설명과 조금 달라도 하는 일은 같습니다. 기능 이름을 기준으로 찾으세요.
</Note>

## 직접 해봅시다

<Steps>
<Step title="Firebase 콘솔에 Google 계정으로 들어갑니다">
로그인하면 프로젝트 목록 화면이 나옵니다. 처음이라면 비어 있습니다.
</Step>
<Step title="새 프로젝트를 만듭니다">
프로젝트를 만드는 버튼을 누릅니다. 이름은 영어 소문자로 짓는 것이 편합니다. 예를 들어 `class-checklist`처럼 무엇을 만드는지 알아볼 수 있는 이름이 좋습니다.

중간에 사용 통계 수집 여부를 묻는 항목이 나올 수 있습니다. 연습용이라면 켜지 않아도 됩니다.
</Step>
<Step title="데이터 보관함(Firestore)을 만듭니다">
프로젝트가 만들어지면 메뉴에서 데이터베이스 기능을 찾습니다. 이 사이트에서는 Firestore Database를 사용합니다.

만들 때 두 가지를 묻습니다. 하나는 위치이고, 하나는 시작 모드입니다.

위치는 한 번 정하면 바꾸기 어렵습니다. 한국에서 쓸 앱이라면 아시아 지역 중 하나를 고르면 됩니다.

시작 모드는 테스트 모드를 고릅니다. 연습하는 동안 막힘 없이 진행하기 위한 임시 설정입니다.
</Step>
<Step title="웹앱을 등록합니다">
프로젝트 설정 화면에 앱을 추가하는 항목이 있습니다. 여기서 웹 앱을 선택합니다. 안드로이드나 iOS가 아니라 웹입니다.

앱 이름을 적으면 등록이 끝납니다. 함께 나오는 호스팅 설정 항목은 지금 선택하지 않아도 됩니다.
</Step>
<Step title="설정값을 확인합니다">
등록이 끝나면 이름과 값이 여러 줄 나옵니다. `apiKey`, `authDomain`, `projectId` 같은 이름이 보입니다.

이 화면을 닫아도 괜찮습니다. 프로젝트 설정 화면의 내 앱 항목에서 언제든 다시 볼 수 있습니다.
</Step>
</Steps>

## 테스트 모드는 임시입니다

<Warning variant="danger">
테스트 모드는 주소를 아는 사람이면 누구나 내 데이터를 읽고 쓸 수 있는 상태입니다. 연습용으로만 쓰는 설정이며, 보통 일정 기간이 지나면 접근이 막힙니다.

인터넷에 공개하기 전에 반드시 접근 권한을 제한해야 합니다. 방법은 [보안 규칙이란?](/security/what-are-security-rules)에 있습니다.

그전까지는 실제 학생 이름이나 개인정보를 넣지 마세요. 연습에는 "모둠 1 준비 완료" 같은 가상의 항목을 씁니다.
</Warning>

## Claude Code에 연결을 요청합니다

이제 Claude Code 앱으로 돌아가 체크리스트 프로젝트를 엽니다.

<PromptBox>
이 프로젝트를 Firebase에 연결하고 싶어. Firebase 콘솔에서 프로젝트와 Firestore를 만들고 웹앱 등록까지 마쳤어.

Firebase 연결에 필요한 준비를 해 주고, 설정값을 넣을 파일을 만들어 줘. 값은 내가 직접 채울 테니 어디에 무엇을 넣어야 하는지 알려 줘. 그 파일이 GitHub에 올라가지 않도록 설정도 함께 확인해 줘.

아직 데이터를 저장하는 기능은 붙이지 마. 연결 준비까지만 하고, 기존 체크리스트 기능과 디자인은 변경하지 마.
</PromptBox>

마지막 문단이 중요합니다. 연결 준비와 기능 추가를 한꺼번에 하면, 오류가 났을 때 어느 쪽 문제인지 알기 어렵습니다.

## 이렇게 나오면 성공입니다

<Success>
Firebase 콘솔에 내 프로젝트가 보이고, 그 안에 비어 있는 Firestore 화면이 열립니다.

프로젝트 설정 화면에서 웹앱 설정값을 다시 볼 수 있습니다.

Claude Code 프로젝트 폴더에 설정값을 넣을 파일이 만들어졌습니다. 값은 아직 비어 있어도 됩니다. 채우는 방법은 다음 페이지에서 다룹니다.
</Success>

## 잘 안 된다면

<Troubleshoot>
<Problem title="데이터베이스 메뉴가 두 종류로 보여요">
Firebase에는 데이터를 보관하는 기능이 하나가 아닙니다. 이 사이트의 예제는 Firestore Database를 기준으로 합니다. 이름을 확인하고 고르세요.
</Problem>
<Problem title="설정값 화면을 닫아 버렸어요">
없어지지 않습니다. 프로젝트 설정 화면에서 내 앱 항목을 열면 같은 값이 다시 나옵니다.
</Problem>
<Problem title="위치를 잘못 골랐어요">
연습 단계라면 프로젝트를 새로 만드는 편이 빠릅니다. 아직 데이터가 없으니 잃을 것도 없습니다.
</Problem>
</Troubleshoot>
