## 이것만 알아두세요

Firebase 화면에서 Google 로그인을 켜고, Claude Code 앱에 요청 한 번을 보내면 로그인 버튼이 생깁니다.

이 페이지에서는 로그인과 로그아웃까지만 합니다. 사용자마다 다른 데이터를 보여주는 일은 아직 하지 않습니다.

## 시작하기 전에

Firebase 프로젝트가 이미 연결되어 있어야 합니다. 아직이라면 [Firebase 프로젝트 만들기](/database/create-firebase-project)를 먼저 하세요.

체크리스트 앱이 데이터베이스에 데이터를 저장하고 있는 상태에서 시작합니다. 로그인은 그 위에 얹는 기능입니다.

## 화면에서 찾아보세요

Firebase 콘솔에서 로그인 기능을 먼저 켜야 합니다. 앱에서 아무리 요청해도 이 설정이 꺼져 있으면 로그인되지 않습니다.

<ScreenGuide>
1. **Authentication** — 메뉴에서 찾을 수 있는 로그인 담당 기능입니다. 처음 들어가면 시작하기 버튼이 보입니다.
2. **로그인 방법(Sign-in method)** — 어떤 방식으로 로그인할지 고르는 목록입니다. 이메일, Google, 익명 등이 나열되어 있습니다.
3. **Google** — 이 목록에서 Google을 선택해 사용 설정합니다. 프로젝트 이름과 지원 이메일을 고르는 칸이 나옵니다.
4. **승인된 도메인(Authorized domains)** — 로그인을 허용할 주소 목록입니다. 지금은 그냥 두고 넘어갑니다.
</ScreenGuide>

<Note>
승인된 도메인은 배포한 뒤에 다시 볼 항목입니다. 인터넷에 공개한 주소를 여기에 추가하지 않으면, 로컬에서는 되는데 배포 사이트에서만 로그인이 안 되는 일이 생깁니다. 자세한 내용은 [배포 후 로그인 테스트하기](/deployment/login-after-deploy)에 있습니다.
</Note>

## 직접 해봅시다

<Steps>
<Step title="Firebase 콘솔에서 Google 로그인을 켭니다">
위의 화면 안내대로 Authentication에서 Google을 사용 설정하고 저장합니다.
</Step>
<Step title="Claude Code 앱에서 체크리스트 프로젝트를 엽니다">
새 프로젝트를 만들지 않고, 지금까지 만들던 폴더를 그대로 엽니다.
</Step>
<Step title="아래 요청을 대화창에 보냅니다">
길어 보여도 그대로 붙여 넣으세요. 상태 목록이 들어 있어서 빠뜨리는 것이 줄어듭니다.
</Step>
<Step title="Claude가 무엇을 고치는지 봅니다">
어떤 파일을 만들고 수정하는지 화면에 나옵니다. 파일을 바꾸기 전에 허락을 묻는다면 내용을 읽고 허락합니다.
</Step>
<Step title="앱을 실행하고 실제로 로그인해 봅니다">
Google 계정 선택 창이 뜨고, 계정을 고르면 원래 화면으로 돌아옵니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
지금 만든 체크리스트 앱에 Firebase Authentication으로 Google 로그인을 붙여 줘.

로그인하지 않았을 때는 로그인 버튼, 로그인했을 때는 사용자 이름과 로그아웃 버튼이 보이게 해 줘. 로그인을 확인하는 중일 때와 로그인에 실패했을 때도 화면이 비어 보이지 않게 처리해 줘. 창을 닫았다 다시 열어도 로그인이 유지되게 해 줘.

먼저 무엇을 어떻게 바꿀지 설명하고, 내가 확인한 뒤에 작업해 줘. 기존 체크리스트 기능과 디자인은 변경하지 마.
</PromptBox>

마지막 두 문장이 중요합니다. 먼저 설명하게 하면 엉뚱한 방향으로 가는 것을 미리 막을 수 있고, 기존 기능을 지켜 달라고 하면 잘 되던 것이 함께 망가지는 일이 줄어듭니다.

## 이렇게 나오면 성공입니다

<Success>
처음 열면 로그인 버튼이 보입니다. 누르면 Google 계정 선택 창이 뜹니다.

계정을 고르면 원래 화면으로 돌아오고, 이름이나 이메일이 화면에 표시됩니다. 로그아웃 버튼도 함께 보입니다.

브라우저를 완전히 껐다 다시 열어도 로그인 상태가 유지됩니다.

로그아웃을 누르면 다시 로그인 버튼만 보이는 처음 상태로 돌아갑니다.
</Success>

아직 체크리스트는 모두가 같은 내용을 봅니다. 로그인만 붙었을 뿐 데이터는 아직 나뉘지 않았기 때문입니다. 이것은 정상입니다.

## 잘 안 된다면

<Troubleshoot>
<Problem title="로그인 버튼을 눌러도 아무 일이 없어요">
Firebase 콘솔에서 Google 로그인을 사용 설정했는지 다시 확인하세요. 저장을 누르지 않고 창을 닫는 경우가 많습니다. 다른 원인은 [로그인이 되지 않아요](/troubleshooting/cant-login)에 정리되어 있습니다.
</Problem>
<Problem title="계정을 골랐는데 다시 로그인 버튼으로 돌아와요">
로그인은 되었지만 앱이 그 결과를 받지 못한 경우입니다. [Google 로그인 후 다시 로그인 버튼으로 돌아와요](/troubleshooting/google-login-loops)를 보세요.
</Problem>
<Problem title="새로고침하면 로그아웃돼요">
로그인 유지 처리가 빠진 경우입니다. "새로고침해도 로그인 상태가 유지되게 해 줘"라고 이어서 요청하세요.
</Problem>
<Problem title="팝업 창이 뜨자마자 닫혀요">
브라우저가 팝업을 막고 있을 수 있습니다. 주소창 근처에 차단 표시가 있는지 확인하고 허용하세요.
</Problem>
</Troubleshoot>
