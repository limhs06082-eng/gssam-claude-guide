## 이것만 알아두세요

지금은 로그인 버튼이 붙어 있어도 로그인하지 않은 사람에게 체크리스트가 그대로 보입니다.

이 페이지에서는 화면을 두 벌로 나눕니다. 로그인 전에는 로그인 화면만, 로그인 후에는 앱 화면이 나오게 만듭니다.

## 쉽게 생각하면

<Analogy>
교무실 문을 하나 세우는 일입니다.

문이 없으면 복도를 지나가는 사람이 안을 그대로 들여다봅니다. 문을 세우면 들어온 사람만 안을 봅니다.

다만 문은 시야를 가릴 뿐입니다. 서류함 자체가 잠기는 것은 아닙니다. 이 차이가 이 페이지 마지막에 나오는 중요한 이야기입니다.
</Analogy>

## 화면은 세 가지 상태가 필요합니다

두 가지로 나누면 될 것 같지만, 실제로는 세 가지입니다.

**확인 중.** 앱이 열리고 나서 "이 사람이 로그인되어 있나"를 알아내기까지 짧은 시간이 걸립니다. 이때 아무 처리도 하지 않으면 로그인 화면이 잠깐 번쩍였다가 앱 화면으로 바뀝니다.

**로그인하지 않음.** 로그인 버튼과 간단한 안내만 보여줍니다.

**로그인함.** 원래 만들던 체크리스트 화면을 보여줍니다.

첫 번째 상태를 빠뜨리는 경우가 정말 많습니다. 요청할 때 명시적으로 넣으세요.

## 직접 해봅시다

<Steps>
<Step title="Claude Code 앱에서 체크리스트 프로젝트를 엽니다">
로그인 버튼이 이미 동작하는 상태에서 시작합니다.
</Step>
<Step title="아래 요청을 보냅니다">
세 가지 화면 상태가 모두 들어 있습니다.
</Step>
<Step title="로그아웃 상태로 접속해 봅니다">
브라우저의 시크릿 창이나 다른 브라우저로 앱 주소를 엽니다. 로그인 화면만 나와야 합니다.
</Step>
<Step title="로그인해서 체크리스트가 나오는지 봅니다">
로그인하면 원래 화면이 그대로 나옵니다.
</Step>
</Steps>

## 이렇게 말해보세요

<PromptBox>
로그인하지 않은 사용자에게는 체크리스트 대신 로그인 화면만 보이게 해 줘.

화면 상태를 세 가지로 나눠 줘. 로그인 여부를 확인하는 중일 때는 잠시 기다리는 표시를 보여주고, 로그인하지 않았으면 로그인 버튼과 짧은 안내만 보여주고, 로그인했으면 지금의 체크리스트 화면을 그대로 보여줘.

로그인 화면이 잠깐 번쩍였다가 사라지는 일이 없게 해 줘. 기존 체크리스트 기능과 디자인은 변경하지 마.
</PromptBox>

## 이렇게 나오면 성공입니다

<Success>
시크릿 창으로 앱 주소를 열면 로그인 화면만 보입니다. 체크리스트는 보이지 않습니다.

로그인하면 원래의 체크리스트 화면이 나옵니다. 항목 추가와 체크가 전부 그대로 동작합니다.

로그아웃을 누르면 다시 로그인 화면으로 돌아갑니다.

새로고침해도 로그인 화면이 번쩍이지 않습니다.
</Success>

## 화면을 가리는 것은 잠그는 것이 아닙니다

여기서 꼭 짚고 넘어가야 할 것이 있습니다.

<Warning title="화면 처리와 데이터 보호는 다른 문제입니다">
지금 한 일은 브라우저 화면에서 체크리스트를 감춘 것입니다. 데이터베이스 쪽에서는 아직 아무것도 바뀌지 않았습니다.

데이터베이스가 여전히 누구나 읽을 수 있는 상태라면, 화면을 가려도 데이터 자체는 밖에서 접근할 수 있습니다.

실제로 잠그려면 데이터베이스 쪽 규칙을 고쳐야 합니다. [보안 규칙이란?](/security/what-are-security-rules)에서 다룹니다.
</Warning>

그렇다고 이 페이지에서 한 일이 쓸모없는 것은 아닙니다. 사용자에게 무엇을 보여줄지 정하는 일은 필요합니다. 다만 그것만으로 안전해졌다고 생각하지 않으면 됩니다.

이 두 가지를 같은 것으로 착각하는 데서 문제가 시작됩니다. 자세한 이야기는 [로그인만 붙이면 안전한가요?](/security/login-is-not-enough)에 있습니다.

## 잘 안 된다면

<Troubleshoot>
<Problem title="로그인 화면이 잠깐 보였다가 사라져요">
확인 중 상태 처리가 빠진 경우입니다. "로그인 여부를 확인하는 동안에는 로그인 화면 대신 기다리는 표시를 보여 줘"라고 이어서 요청하세요.
</Problem>
<Problem title="로그인했는데도 계속 로그인 화면이 나와요">
로그인 결과를 화면이 받지 못하는 경우입니다. [로그인이 되지 않아요](/troubleshooting/cant-login)를 보세요.
</Problem>
<Problem title="화면을 나눴더니 체크리스트 기능이 이상해졌어요">
"화면을 나누기 전 상태로 되돌린 다음, 기존 체크리스트 코드는 그대로 두고 화면 분기만 다시 붙여 줘"라고 요청하세요.
</Problem>
</Troubleshoot>

## G쌤 팁

<TeacherTip>
테스트는 반드시 시크릿 창에서 하세요. 평소 쓰는 창은 이미 로그인되어 있어서, 로그인하지 않은 사람에게 무엇이 보이는지 알 수가 없습니다.

저는 시크릿 창 하나를 늘 띄워 놓고 작업합니다. 왼쪽은 로그인한 화면, 오른쪽은 처음 오는 사람의 화면입니다. 이렇게 두면 잘못된 것이 바로 보입니다.

배포한 뒤에도 같은 방법으로 한 번 더 확인하세요. [배포 후 로그인 테스트하기](/deployment/login-after-deploy)에 순서가 정리되어 있습니다.
</TeacherTip>
