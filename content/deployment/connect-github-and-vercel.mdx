## 이것만 알아두세요

이 페이지에서는 Vercel에 가입하고, GitHub에 올려 둔 내 프로젝트를 Vercel로 가져옵니다.

이 작업은 Claude Code가 대신 해 줄 수 없습니다. 계정 로그인과 서비스 연결은 사용자가 브라우저에서 직접 해야 합니다. 어렵지는 않습니다. 버튼을 몇 번 누르면 끝납니다.

## 시작하기 전에 확인할 것

아래 두 가지가 준비되어 있어야 합니다.

- GitHub 계정이 있고, 내 프로젝트가 GitHub 저장소에 올라가 있습니다. 아직이라면 [GitHub에 프로젝트 올리기](/code/push-to-github)를 먼저 보세요.
- 브라우저에서 GitHub에 로그인되어 있습니다. 연결 과정에서 GitHub 로그인 창이 뜰 수 있습니다.

두 가지 중 하나라도 준비되지 않았다면 여기서 멈추고 GitHub 쪽을 먼저 끝내세요. 순서를 건너뛰면 Vercel 화면에서 가져올 저장소가 아예 보이지 않습니다.

## 직접 해봅시다

<Steps>
<Step title="브라우저에서 vercel.com에 접속합니다">
주소창에 vercel.com을 입력합니다. Claude Code 안의 브라우저 화면이 아니라, 평소 쓰는 브라우저를 여는 편이 편합니다.
</Step>
<Step title="GitHub 계정으로 가입합니다">
가입 화면에서 GitHub로 계속하는 선택지를 고릅니다. 이렇게 하면 비밀번호를 새로 만들지 않아도 되고, GitHub 연결도 함께 끝납니다.

GitHub 화면으로 넘어가 Vercel에게 접근을 허용할지 묻습니다. 어떤 권한을 요청하는지 한 번 읽어 보고 승인합니다.
</Step>
<Step title="개인용으로 시작합니다">
팀 이름이나 용도를 묻는 화면이 나올 수 있습니다. 혼자 연습하는 단계라면 개인용을 고릅니다. 나중에 바꿀 수 있습니다.
</Step>
<Step title="저장소를 가져오는 메뉴를 찾습니다">
새 프로젝트를 만들거나 저장소를 가져오는(Import) 메뉴가 있습니다. 여기를 누르면 내 GitHub 저장소 목록이 나타납니다.
</Step>
<Step title="내 프로젝트 저장소를 고릅니다">
목록에서 내가 만든 프로젝트 이름을 찾아 가져오기를 누릅니다.

목록에 아무것도 없거나 내 저장소가 보이지 않으면, 어떤 저장소에 접근할지 고르는 설정에서 해당 저장소를 추가로 허용해야 합니다. GitHub 쪽 설정 화면으로 이동하게 됩니다.
</Step>
<Step title="설정은 그대로 두고 넘어갑니다">
프로젝트 이름, 빌드 방식 같은 설정 항목이 보입니다. 대부분 Vercel이 알아서 알맞게 채워 둡니다. 무슨 뜻인지 모르겠다면 손대지 말고 그대로 두세요.

이 화면에서 배포 버튼을 누르면 바로 첫 배포가 시작됩니다. 실제 배포는 다음 페이지에서 이어서 다룹니다.
</Step>
<Step title="환경변수 항목은 지금 비워 둡니다">
설정 화면에 환경변수(Environment Variables)를 넣는 칸이 함께 있을 수 있습니다. 데이터베이스나 로그인을 아직 붙이지 않았다면 넣을 값이 없습니다.

비워 둔 채로 넘어가세요. 나중에 필요해지면 [Vercel에 환경변수 등록하기](/deployment/environment-variables-on-vercel)에서 등록합니다.
</Step>
</Steps>

## 이렇게 나오면 성공입니다

<Success>
Vercel 화면에 내 프로젝트가 하나 생기고, 그 안에 GitHub 저장소 이름이 함께 표시됩니다.

이제 이 저장소에 새 내용이 올라갈 때마다 Vercel이 자동으로 다시 배포합니다. 이 연결 작업은 프로젝트마다 처음 한 번만 하면 됩니다.

프로젝트를 새로 만들 때는 이 과정을 다시 한 번 합니다. 두 번째부터는 훨씬 빠릅니다.
</Success>

## 잘 안 된다면

<Troubleshoot>
<Problem title="저장소 목록에 내 프로젝트가 없어요">
두 가지를 확인하세요. 첫째, 프로젝트가 실제로 GitHub에 올라가 있는지 봅니다. github.com에서 내 저장소 목록을 열어 파일이 보이면 올라간 것입니다.

둘째, Vercel에게 그 저장소를 볼 권한을 주었는지 확인합니다. 저장소 접근 설정에서 전체 저장소를 허용하거나, 해당 저장소를 목록에 추가합니다.
</Problem>
<Problem title="GitHub에 프로젝트를 올리는 것부터 막혔어요">
[GitHub에 올라가지 않아요](/troubleshooting/github-push-fails)에서 흔한 원인을 순서대로 확인할 수 있습니다.
</Problem>
<Problem title="화면이 안내와 조금 달라요">
Vercel의 화면 구성은 업데이트되면서 바뀝니다. 버튼 위치가 달라도 하는 일은 같습니다. 가입, 저장소 가져오기, 배포라는 세 가지 이름을 기준으로 찾아보세요.
</Problem>
</Troubleshoot>

## G쌤 팁

<TeacherTip>
연결 과정에서 권한을 승인하는 화면이 여러 번 나옵니다. 습관적으로 넘기지 말고, 어떤 권한을 요청하는지 한 번씩 읽어 보세요.

Vercel이 요청하는 것은 내 저장소를 읽어서 배포하는 데 필요한 권한입니다. 학교 계정이나 공용 계정으로 가입한다면 특히 무엇을 허용하는지 확인해 두는 편이 좋습니다.
</TeacherTip>
