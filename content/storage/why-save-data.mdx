## 이것만 알아두세요

Claude Code로 만든 웹앱은 처음에는 새로고침하면 입력한 내용이 모두 사라집니다.

고장이 아닙니다. 아직 어디에도 저장하라고 말하지 않았기 때문입니다. 이 과정에서 그 저장을 붙입니다.

## 먼저 겪어 봅시다

연습에는 아주 단순한 체크리스트 앱이면 충분합니다. 이미 만들어 둔 것이 있다면 그것을 쓰고, 없다면 첫 단계에서 바로 만듭니다. 5분이면 됩니다.

<Steps>
<Step title="체크리스트 앱이 없다면 먼저 만듭니다">
Claude Code 앱에서 새 폴더를 열고 아래 문장을 보냅니다. 저장 기능은 일부러 넣지 않습니다. 사라지는 것을 직접 봐야 하기 때문입니다.

<PromptBox>
아주 단순한 개인 체크리스트 웹페이지를 만들어 줘. 위쪽에 입력 칸과 추가 버튼, 아래에 항목 목록이 있고, 항목을 누르면 완료 표시가 되고, 삭제 버튼으로 지울 수 있으면 돼. 파일은 index.html 하나로 만들고, 데이터 저장 기능은 아직 넣지 마.
</PromptBox>

더 제대로 된 앱으로 만들고 싶다면 나중에 [개인 업무 체크리스트](/projects/personal-checklist) 프로젝트에서 처음부터 끝까지 다시 만들어 봅니다.
</Step>
<Step title="앱을 브라우저에서 엽니다">
Claude Code 앱의 미리보기 화면에서 열어도 되고, 브라우저 주소창에 주소를 넣어 열어도 됩니다.
</Step>
<Step title="항목을 서너 개 추가하고 몇 개를 체크합니다">
"출석부 확인", "가정통신문 배부"처럼 아무 내용이나 적습니다.
</Step>
<Step title="새로고침합니다">
키보드의 F5를 누르거나 브라우저의 새로고침 버튼을 누릅니다.
</Step>
<Step title="화면을 확인합니다">
방금 넣은 항목이 모두 사라지고 처음 상태로 돌아갑니다.
</Step>
</Steps>

## 왜 사라질까요

<Analogy>
지금까지 만든 웹앱은 칠판 같습니다.

칠판에 적으면 잘 보이고 지우기도 쉽습니다. 하지만 교실 문을 닫았다 다시 열면, 누군가 그새 칠판을 지워 놓았습니다.

새로고침이 그 문을 여닫는 일입니다. 화면을 다시 그리면서 적혀 있던 내용이 사라집니다.
</Analogy>

조금 더 정확히 말하면 이렇습니다. 지금 입력한 내용은 브라우저가 화면을 그리는 동안에만 잠시 기억하고 있는 상태입니다. 화면을 다시 그리면 그 기억도 함께 초기화됩니다.

계속 남기려면 화면과 별도로 어딘가에 적어 두어야 합니다. 그 "어딘가에 적어 두는 일"이 데이터 저장입니다.

## 저장을 붙이면 무엇이 달라지나요

저장이 붙기 전과 후는 앱의 성격 자체가 다릅니다.

저장이 없으면 앱은 계산기에 가깝습니다. 열 때마다 처음부터 시작하고, 창을 닫으면 흔적이 없습니다. 타이머나 무작위 뽑기처럼 매번 새로 시작해도 되는 도구라면 이대로가 오히려 편합니다.

저장이 붙으면 앱은 수첩에 가까워집니다. 어제 적어 둔 것이 오늘도 있고, 계속 쌓입니다. 체크리스트, 메모, 자리배치처럼 이어서 쓰는 도구는 여기서부터 쓸모가 생깁니다.

지금 만들고 있는 것이 계산기인지 수첩인지 한 번 생각해 보세요. 수첩이라면 저장이 필요합니다.

## 어디에 저장할 수 있나요

저장할 곳은 크게 두 가지입니다.

**내 브라우저 안.** 지금 쓰는 컴퓨터의 브라우저 안에 적어 둡니다. 설정이 간단하고 회원가입이 필요 없습니다. 이것이 다음 페이지에서 배울 [LocalStorage](/storage/what-is-localstorage)입니다.

**인터넷 너머의 서버.** 인터넷에 있는 보관소에 적어 둡니다. 다른 컴퓨터에서도 보이고 여러 사람이 같이 쓸 수 있습니다. 대신 준비할 것이 더 많습니다. 이것은 [데이터베이스 연결하기](/database) 과정에서 다룹니다.

이 과정에서는 첫 번째부터 시작합니다. 개인이 혼자 쓰는 도구라면 이것으로 충분한 경우가 많습니다.

## 지금 정해 둘 것

저장을 붙이기 전에 스스로 답해 볼 질문 두 개가 있습니다.

첫째, 이 앱을 나 혼자 씁니까, 다른 사람도 함께 씁니까?

둘째, 한 대의 컴퓨터에서만 씁니까, 학교 컴퓨터와 집 노트북에서 모두 씁니까?

둘 다 "나 혼자, 한 대에서"라면 LocalStorage로 끝납니다. 하나라도 아니라면 나중에 데이터베이스가 필요해집니다. 지금 답이 확실하지 않아도 괜찮습니다. [어떤 앱까지 LocalStorage로 충분할까요?](/storage/is-localstorage-enough)에서 다시 정리합니다.

## 잘 안 된다면

<Troubleshoot>
<Problem title="새로고침해도 내용이 남아 있어요">
이미 저장 기능이 들어가 있는 것입니다. Claude에게 "지금 이 앱은 데이터를 어디에 어떻게 저장하고 있어? 코드를 확인하고 쉬운 말로 설명해 줘"라고 물어보면 알 수 있습니다.
</Problem>
<Problem title="Claude가 저장 기능까지 넣어 버렸어요">
"저장 기능은 빼 줘. 새로고침하면 사라지는 상태로 두고 싶어"라고 요청하세요. 이 페이지에서는 사라지는 것을 먼저 겪어 보는 것이 목적입니다.
</Problem>
</Troubleshoot>
